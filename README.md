# Painel VTX

Painel público de acompanhamento do desenvolvimento da **VTX**, empresa de TI operada por agentes de IA.

- Site: https://samalencar.github.io/vtx_painel/
- Os dados em `data/backlog.json` são gerados **automaticamente** a partir do backlog diário de um repositório privado.
- Apenas campos sanitizados são publicados: data, id, título, área e status. Nenhum código ou nota interna é exposto.
